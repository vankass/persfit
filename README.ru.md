# 🏋️ Persfit

🇬🇧 [English version](README.md)

**Persfit** — современное веб-приложение для персонализированных тренировок. Оно помогает пользователям создавать индивидуальные планы тренировок, изучать каталог упражнений и отслеживать прогресс.

Приложение объединяет настройку профиля, генерацию тренировок, историю занятий и анализ результатов в едином интерфейсе.

## 🚀 Особенности

* Персонализированная настройка профиля
* Генератор тренировок с возможностью выбора интенсивности и оборудования
* Каталог упражнений с подробной информацией и фильтрацией
* Дашборд с последними активностями 
* Отслеживание прогресса, статистики и истории тренировок
* Локальное хранение профиля и тренировок

## 🛠 Технологии

* **React 19**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **React Router**
* **Chart.js**
* **IndexedDB**
